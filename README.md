# 八字學中文｜排盤

BaZi (Four Pillars) and Zi Wei Dou Shu charts with pinyin, English and Japanese.

- BaZi: https://chinesewithlily.github.io/bazi/
- Zi Wei: https://chinesewithlily.github.io/bazi/ziwei/

Engines (MIT): [lunar-javascript](https://github.com/6tail/lunar-javascript) v1.7.7; [iztro](https://github.com/SylarLong/iztro) v2.6.3 and [lunar-lite](https://github.com/SylarLong/lunar-lite), bundled from source into ziwei/iztro.js. Licence files included.
